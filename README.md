# 身份证号码解析器

一个隐私优先、完全在浏览器本地运行的中国大陆公民身份号码解析与格式校验工具。

- **本地处理**：号码解析、规则校验与格式转换均在当前浏览器内完成。
- **离线可用**：页面代码和行政区划数据全部随项目提供，核心功能不需要联网。
- **零运行依赖**：使用原生 HTML、CSS 和 JavaScript，无需安装依赖或启动后端。
- **数据可控**：没有账号、服务端存储、统计脚本或埋点；本地历史可逐条删除或一键清空。

> [!IMPORTANT]
> 本工具只检查号码是否符合公开编码规则，不能证明证件、号码或持证人真实存在，也不应作为身份认证或实名核验依据。

## 安全与隐私

| 数据或行为    | 处理方式 |
|----------| --- |
| 输入的身份证号码 | 仅在当前页面中解析，不会由本项目上传到服务器 |
| 解析历史     | 校验通过后最多保存 20 条到当前浏览器的 `localStorage`，可随时删除 |
| 行政区划查询   | 读取项目内置的 `src/region-data.js`，不会发起数据请求 |
| 查看地图     | 仅在用户主动点击后打开高德地图，只传递地区名称，不传递身份证号码 |
| 统计与广告    | 本项目不包含统计、广告、追踪 SDK 或第三方运行时依赖 |

页面配置了基础内容安全策略（CSP）并禁用来源信息发送，以减少意外资源加载和信息泄露。

请同时了解以下边界：

- `localStorage` 是浏览器本地明文存储，并非加密保险箱。共用电脑或处理敏感数据时，建议在完成后清空历史。
- 浏览器扩展、本机恶意软件或被修改后的项目文件仍可能读取页面内容；请从可信来源获取代码，并保持浏览器和操作系统更新。
- 点击“查看地图”后即进入第三方网站，第三方会收到地区关键词以及常规网络信息，其隐私政策不受本项目控制。
- 隐私要求较高时，推荐下载后本地运行。

下载或克隆项目后，直接双击打开根目录的 `index.html`。无需执行 `npm install`，无需启动本地服务器，断网也可使用核心解析功能。

## 功能

- 解析省、市、区县、出生日期、性别与顺序码。
- 检查号码长度、字符、行政区划、日期、顺序码和校验位。
- 按 GB 11643—1999 规则校验 18 位号码。
- 支持 15 位旧号码与适用的 18 位号码相互转换。
- 识别数据集中已撤销或更名的历史行政区划。
- 展示公历、农历、星期和星座信息。
- 提供校验权重、余数映射和虚构号码计算示例。
- 在当前浏览器保存最近 20 条有效记录，并支持复制、删除和清空。
- 可主动打开地图查看对应行政区位置，不会把身份证号码加入地图链接。

## 支持范围

- 支持中国大陆 18 位公民身份号码。
- 兼容 15 位旧号码，出生年份按 `19YY` 补全。
- 18 位转 15 位时移除世纪位 `19` 和末位校验码；2000 年及以后出生的号码无法无歧义转换。
- 不处理港澳台居民居住证、外国人永久居留身份证等其他证件。
- 结果仅用于编码规则检查，不提供联网身份核验。

## 本地测试

测试基于 Node.js 内置能力，不需要安装第三方包。Node.js 18 或更高版本下运行：

```powershell
npm test
```

测试号码均由程序生成或来自公开规则示例，不包含真实个人身份信息。

## 规则与数据

- 编码规则：[GB 11643—1999《公民身份号码》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=080D6FBF2BB468F9007657F26D60013E&refer=outter)
- 行政区划数据：[yescallop/areacodes](https://github.com/yescallop/areacodes)，覆盖 1981—2025 年县级以上历史代码
- 区划数据许可：CC0 1.0

区划数据已压缩到 `src/region-data.js`。对于已停用的地址码，工具会显示历史名称、停用年份和数据集中可用的现行对应地区。
